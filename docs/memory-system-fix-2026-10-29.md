# 记忆系统修复与部署记录

日期：2026-10-29。对应 `memory-system-audit-2026-10-29.md` 的 12 项发现。基于审查时已有的工作区改动继续修改，未撤销此前的人格成长与界面更新。

## 实现

| 审查项 | 修复 |
| --- | --- |
| 安装资源不一致 | `tools/sync_fish_assets.py` 生成全部 12 个运行模块副本及向导清单，`--check` 验证；安装资源独立状态与心跳测试覆盖城市配置。 |
| 数据提升为 system 规则 | `memory_policy.py` 统一信任约束；聊天记忆、昵称、头像、引述改为结构化 user 资料块；成长、反思及行动入口声明证据不是指令。 |
| 新旧事实冲突 | `memory_history` 保留被更新事实的来源和关联回复，但让其退出当前召回；历史检索显式开启。旧事件不能更新更晚的有来源事实。 |
| 混合记录先限量 | 先按类型、人物、范围筛选，再限量；提炼还补充相关旧事实检索。反思轮转人物组，无合格依据不扣积分。 |
| 秘密凭据长期化 | 事件、经历、短期消息、日志写入脱敏；长期 fact/belief/intention 写入校验。旧数据迁移前备份，脱敏后隔离含凭据的认识并撤销失效画像。 |
| 旧积压饥饿 | 真正最早的可重试事件优先；持久化失败次数和退避时间，其他人物可继续；状态接口提供积压及最老等待时间。 |
| 逾期待办归零 | 明确日期允许合理的过去窗口，未知日期仍为 0；保留有效 QQ 事件时间，区别于处理时间。 |
| 主动行动缺少人格和起因 | 共享人格渲染；第二阶段按目标范围重新读取第一阶段的依据。私有跟进只提供联系主人的工具，公开行动只读 global 背景，额外校验返回工具名。 |
| 人工移除特质复活 | 持久化人工否决，生成与写入同时检查；人工已有内容的维度阻止新自动条目；画像版本包含人工状态与否决。关键行为控制不由自动进化修改。 |
| 同名人物混淆 | 记忆资料携带稳定人物代号、来源范围、类型和时间。 |
| 平台动作不入记忆 | 审批后的空间发布、小黑盒帖子/评论在真正执行结束后记录结果，以审批 ID 去重；其他自主变更工具记录结果，读工具不自动产生事实。 |
| 经历无限活跃与全量检索 | 自身经历按 300 条及 24h 保护规则归档；SQLite 字符倒排索引限定候选后重排，历史仍可显式搜索，删除同步清理索引。 |

没有引入向量服务、图数据库或额外代理。索引用 SQLite 普通索引表实现，不依赖不同 Python/Android 构建是否包含 FTS 扩展。保护新记录及固定记录仍可能使活跃数暂时超过目标。

行为策略作了明确收紧：静默时段、审批、启用平台由用户控制；人工保存行为字段会锁定，自动进化重新校验并发变更。目前自动进化只可能调整未锁定的聊天尺度。画像的人工维度优先于新自动条目。
