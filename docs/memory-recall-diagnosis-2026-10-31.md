# 记忆与聊天只读诊断（2026-10-31）

本记录仅写机制和匿名结论，不收录设备上的私人聊天正文、身份或数据库。用户要求检查近期聊天中的记忆问题，本轮未修改运行源码、记忆、设置或模型配置，未调用模型和发送消息。

## 已确认的问题

### 1. 已保存的有效证据未被召回

设备上同时存在原始用户事件及据此提炼的 active 事实，待处理事件数为零，排除本案例因后台提炼积压、服务重启清空记忆而失败。相关运行模块的换行归一化 SHA-256 与本地源码一致。

`qq_bot.py` 将最近两条短期消息（包括助手回复）与当前用户问题拼为一个查询。`MemorySystem.retrieve` 用整段文字与每条记忆计算字符重叠，相关度小于 0.08 就剔除。当前问题的主题在长背景中被稀释，短事实还会因其表达不同而低分。

按当轮短期消息和现存数据库的当时可见记录在内存中重放：直接事实相似度约 0.0348，原始用户事件约 0.0351，均低于阈值；相邻的不完整陈述的提炼记录约 0.0861，被保留。八条召回结果没有直接答案。这是索引召回与排序问题，不是用户没有说过。

### 2. 助手历史回复挤占事实，并产生自我解释循环

首轮八条结果中五条是 experience，后续一轮八条全是 experience。查询中保留助手刚说的话，会使包含同样说法的旧 experience 更相似，反过来再次进入回答背景。

当轮重放还可看到：一次回答前原始用户证据已能召回，但输出依然沿用此前“没有留下信息”的解释。因此不能将所有错误仅归因于检索；模型在混合证据下也未可靠处理来源和冲突。后续再追问来源时，直接原话又落出阈值，助手转而否认自己有出处。聊天模型的自述不能作为真实程序故障原因。

### 3. 来源 ID 没有自动展开为可核对的原始证据

`evidence_data` 提供 source_ids，但没有随相关 experience/fact 自动提供其有效原始用户事件。模型能看到 ID 不等于能访问该记录。experience 文本又混合了对方原话及助手实际回复，容易把已生成的错误解释当作对方事实。

### 4. 低价值事实及过期“待办”污染上下文

本例中普通即时提问被提炼为 intention，例如要求解释上一句的意思；回答完后仍 active。`working_context` 直接选最近三条 active intention，与当前话题无关的旧问题也进入背景。临时状态和不完整片段被逐字改写为 fact，增加噪声。现有“只记录明确约定与待反馈事项”的提示未可靠落实。

### 5. 时间信息没有贯通短期聊天链路

short_term 表有 ts，但 `get_short_term` 只返回 role/content，prompt 中历史消息没有时间。跨日后旧消息的“明天、今晚、刚才”缺少可靠锚点。当前 system 时间虽然存在，不能据此保证模型正确理解没有时间标签的旧消息。近期聊天确有跨日时间误判，但本轮未重放主动行动的历史完整提示，不能将其原因单独锁定为这一点。

## 重放的边界

诊断工具只以只读方式打开手机数据库，使用 SQLite backup 复制到临时内存连接；retrieve 的 last_access 写入仅作用于内存副本。按历史消息时刻排除更晚插入的记忆，恢复同一查询公式和短期窗口，不调用真实模型。历史完整 LLM 请求未保存，记忆状态和 occurred_at 的历史版本也未保存，因此这是代码路径的离线重放，不是原请求逐字节抓包；分数的年龄项以诊断时间计算。本例关键事实未被删除或替换，相关性硬阈值不受年龄项影响。

## 修复应覆盖的范围

- 将当前用户问题与背景分开检索及评分，保留用户话题线索，避免助手回复支配查询；对“问题类别与答案表达不同”的情形增加通用的语义或话题检索能力，不能硬编码此次内容，也不能只降低阈值。
- 人物事实查询优先原始用户证据和有效事实，限制助手 experience 占位；为相关记录展开有效且可见的原始来源，处理冲突时保留证据优先级。
- 召回不足不能表述为“用户没说过”；没有运行诊断依据时不能编造丢失、截断或已保存的原因。
- 收紧即时提问进入长期事项的规则，并为已有事项建立完成机制；避免无意义事实淹没稳定信息。
- 为短期历史保留时间、渠道及说话人元信息；以匿名语义场景评估跨日和多轮追问。

后续验收应包含：有原始证据但问法不同、无关键词重叠、连续追问来源、助手旧错误污染、事实更新、删除、隐私和跨日。现有合成检索基准主要验证与原文高度相似的查询，不能据其通过宣称真实记忆问题已解决。

只读工具：`tools/inspect_memory_chat_device.py`。默认输出脱敏诊断供本地查看；`replay` 模式只在内存副本中重建本次查询。不要将其真实输出或数据库提交到公开仓库。
