# v1.0.41 — 链路冲突修复

版本：`1.0.41+55`。Android 8.0+。

- 人工事实拒绝更早事件覆盖；后来的明确陈述仍可按证据更新。待办修订保留类型、日期、状态和联系标记。
- 行为页可控制 QQ/小黑盒互动，工具选择、执行和 QQ 业务处理均检查开关；管理诊断连接保留。主动消息、戳一戳和点赞共用 00:00–08:00 静默限制。
- 旧事件只衰减自己的情绪增量；心跳通过修订号拒绝旧写入，来源删除或人格重置后丢弃在途结果。
- 审批历史区分授权和执行结果：执行中、平台确认、失败/部分完成、未确认。未知结果不自动重试，平台确认不表示他人已读。
- 自省显示实际应用和被拦截的变更；主动和被动聊天共享聊天尺度；表情包固定语法与动态标签分开。
- 浏览后可以提出评论审批；QQ 非公开读结果只用于联系主人。Claude/Gemini 使用经白名单及参数校验的 JSON 计划，错误输出停止本轮；OpenAI 兼容接口保留原生工具调用。
- 同步脚本同时覆盖 Python、部署脚本和 OneBot 模板。

先安装新 APK，再在部署页更新鱼脑；只安装 APK 不更新已运行的 Python。首次审批结构升级前，本地备份为 `<数据库>.pre-link-v1.db`。旧已处理审批与重启时在途执行标为未确认，不自动重放。

回退前停止服务并成套恢复数据库与旧源码；备份含私人内容，应留在本机保管。验证结果见 [修复记录](../link-conflict-fix-2026-10-29.md)。构建不代表已部署手机，也不代表已完成真实模型或平台验证。
