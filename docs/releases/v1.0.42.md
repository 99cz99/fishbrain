# v1.0.42：QQ 分段确认、上下文与图片缓存修复

版本：`1.0.42+56`，Android 8.0+。已构建并覆盖安装连接的手机。

- 每段发送独立落库。自身消息回报和迟到 API 成功响应可确认已发送段；确认后继续尚未发送的后续段，不重发未知结果的段落。
- 已提交内容按段写入聊天上下文，并显示未确认状态；确认后原位更新。未知发送不作为成功聊天行为用于人格成长。
- 新消息或控制条件变化取消旧尾段，正常取消记为信息日志；进程重启不重放未知发送或旧尾段。
- 同步调整鱼脑与 OneBot 等待时间，接通自身消息回报。配置迁移保留现有凭据和其他连接。
- 图片优先尝试 QQ 原图缓存，并校验文件 MD5。API 文件与 URL 独立尝试，错误日志只保留来源、类型和 HTTP/API 状态。
- 升级向导同步写入 OneBot 模板并迁移实际账号配置；需要时 QQ 会短暂重连。

安装 APK 后，已有用户仍需在部署页更新鱼脑才能替换运行中的 Python。数据库首次增加发送日志前自动备份为 `<数据库>.pre-qq-delivery-v1.db`。重启后不自动恢复旧发送，以免重复或补出过时消息。

验证：142 项 Python 回归、14 项 Flutter 测试、Flutter 静态分析及 APK 资源一致性检查通过。真机历史故障图片已恢复读取，账号连接与数据库完整性检查通过。本次未发送真实 QQ 测试消息，尚未验证真实网络下的新一轮多段聊天。
