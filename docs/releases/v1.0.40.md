# v1.0.40 — 记忆可靠性与人格成长更新

版本：`1.0.40+54`。Android 8.0+。

本版补齐记忆、人格成长与主动行动的联动，并修复安装资源与 Python 主源码不一致的问题。

## 更新内容

- 正常 QQ 回复和平台动作可形成有来源的自身经历，经过独立隐私审查提炼统一人格；人工编辑和否决优先，相关依据失效时撤销自动特质。
- 事实更新保留历史证据，但旧原话退出当前知识召回；稳定人物代号、时间、范围和记忆类型减少同名混淆。
- 修复近期闲聊遮住旧事实和反思依据、反思空跑扣积分、旧积压等待过久，以及稍微逾期的待办被清成日期未知等问题。
- 记忆正文和外部对话资料与 system 行为规则分离；常见凭据写入脱敏，升级时备份并清理旧内容中的凭据，隔离相关长期认识。
- 聊天、心跳和主动行动共享人格规则；私有跟进与公开行动分别读取对应范围的背景，平台动作在执行结束后记录确认、未确认或失败结果。
- SQLite 字符倒排索引缩小召回候选，自身经历分层归档，删除同步清理索引。当前仍无向量检索。
- 设置页显示成长状态与最近更新时间，手动自省后刷新；画像保存通过版本校验避免覆盖后台更新。
- 自动同步全部运行模块与安装向导清单，补齐天气和四维情绪依赖，修复配置城市后读取生命状态报错。

## 升级步骤

1. 下载 `app-release.apk`，覆盖安装。
2. 在 app「部署」页更新鱼脑 Python 代码；仅安装 APK 不会更新已有鱼脑服务。
3. 更新完成后检查鱼脑状态、QQ 连接和记忆页。保留现有配置、登录和数据库，无需重装 QQ。

首次使用按部署向导完成 Termux 环境检查、模型接口设置和 QQ 配置。

迁移前保留 SQLite 备份，升级策略备份文件名为 `<数据库>.pre-memory-policy-v3.db`。迁移会脱敏常见秘密凭据，隔离含凭据的长期认识；备份仍含原始数据，需留在本机妥善保管。停止服务后才能按[记忆系统文档](../memory-system.md)恢复备份。

此 APK 沿用现有本地升级签名并已覆盖安装验证；本版不更换应用签名。自建包需保持签名一致才能覆盖已有安装。
